睡眠サイクルとは？90分の仕組みと個人差

睡眠は、深い眠りのノンレム睡眠と、体は休みつつ脳が活発に動くレム睡眠が交互に繰り返されて構成されています。この1セットが平均して約90分とされ、一晩に4〜6回ほど繰り返されます。

ノンレム睡眠とレム睡眠

入眠直後はまずノンレム睡眠から始まり、眠りの深さが徐々に浅くなりながら60〜80分ほど続いた後、レム睡眠が10〜30分ほど訪れて1サイクルが終わります。レム睡眠のタイミングは比較的目が覚めやすいとされ、「サイクルの節目で起きるとすっきりする」という考え方の根拠になっています。

90分はあくまで平均値

「睡眠サイクル=90分」という数字は広く知られていますが、これは平均的な値であり、実際には人によって70分〜110分程度の幅があるとされています。同じ人でも、その日の疲労度や体調、年齢によってサイクルの長さは変動します。また最初のサイクルは短く、後半のサイクルほど長くなる傾向があるともいわれます。

そのため「90分の倍数で起きれば必ずすっきり目覚められる」というわけではなく、あくまで就寝・起床時刻を検討するための目安の一つとして捉えるのがよいとされています。

サイクルの区切りを意識する意味

睡眠時間そのもの（一般的に成人で7〜9時間程度が目安とされます）を確保することがまず重要で、その上でサイクルの区切りに近いタイミングで起床時刻を設定すると、深い眠りの最中に起こされる可能性を減らせる、という考え方です。本ツールの計算結果も、この目安に基づいた参考値としてご利用ください。

日中の強い眠気が続く、いびきや呼吸の乱れを指摘される、眠っても疲れが取れないといった症状が続く場合は、睡眠障害が疑われることがあります。自己判断せず、医療機関へご相談ください。
